# PCIC React Leaflet Components

An `npm`-installable package of PCIC-developed
[React Leaflet](https://react-leaflet.js.org/en)
components for use across projects. It is installed directly from GitHub at a
version tag, not from an npm registry.

This repo also contains a "playground" React app that demonstrates the
components. The playground app code contains some key examples of how to
use the contents of this package.

## Development

```
npm run install:all   # install the library and the playground
npm run dev           # watch-build the library and serve the playground
npm test              # run the test suite
```

The library is built with Vite and tested with Vitest. See
[Contributing](docs/contributing.md) for the dev loop, testing, CI and
releasing.
